# Parrot Service

Parrot Service covers cloud calling and the services users manage through Parrot.

## Scope

- Accounts, devices and call management.
- The Console and Web Phone experience.
- Voice provider integrations.

## Current status

This repository provides public issue tracking and product planning. Product source code is not currently published here.
